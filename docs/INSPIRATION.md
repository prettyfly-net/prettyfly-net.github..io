# UX Inspiration Notes

The PrettyFly storefront uses retail patterns commonly found in established school-supply e-commerce sites:
- promotion and utility bars
- a prominent search experience
- launch / best seller / deal merchandising
- category and collection discovery
- filter-heavy product listing pages
- order tracking and customer care
- shipping / quality reassurance
- wholesale, coupon, policy, and legal links in the footer

The PrettyFly implementation uses original branding, product names, collection names, artwork, layout styling, and written copy.

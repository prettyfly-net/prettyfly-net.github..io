# Upload PrettyFly Correctly

This repaired version is intentionally packaged with fewer files to avoid partial browser uploads.

## Upload

- Extract the ZIP.
- Upload the CONTENTS of the extracted folder to the repository root.
- `index.html` must be at the root.
- Keep the `assets` folder and its subfolders intact.
- Do not mix files from older PrettyFly versions.

## Required files to verify on GitHub

- `index.html`
- `shop.html`
- `product.html`
- `assets/css/styles.css`
- `assets/js/app.js`
- `assets/js/catalog.js`
- `assets/images/hero/hero-signature.svg`
- `assets/images/hero/hero-desk.svg`
- `assets/images/branding/wordmark.svg`

If older files are already in the repository, replace them with this version instead of combining versions.
